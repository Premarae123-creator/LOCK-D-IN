# LOCK-D-IN LIVE

**LOCK IN • STAY UP • GET PAID**

## Deploy on Render
- Language: Node
- Build command: `npm install`
- Start command: `npm start`

Upload `server.js`, `package.json`, `README.md`, and keep `index.html` inside the `public` folder.

This prototype does not collect wagers, process payments, hold funds, or automate payouts. Obtain jurisdiction-specific legal review before using paid chance-based entries or wager-funded cash prizes.

Rooms are currently stored in server memory and reset if the server restarts.
